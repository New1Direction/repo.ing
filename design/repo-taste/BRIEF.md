## Blank profile for another product

A new project's profile should identify:
- Product purpose, user and dominant action.
- Current code/framework, fonts and token source files.
- Actual colour roles in both themes; asset filenames and licence/reference provenance.
- Signature object, visual texture, character and motion limits.
- Routes and page-vs-app classification.
- Product data, source-of-truth and restricted operations.
- Known good reference screenshots; explicit anti-examples.
- Three initial routes to improve and objective release checks.

The PORTABLE CORE is shared. Each product has a separate PROFILE. Do not homogenise Colony.fun, FYNCH and repo.ing by inheriting the same visual skin.
