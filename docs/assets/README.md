# Repository images

These files are presentation assets, not live analytics exports.

| Asset | Source |
| --- | --- |
| `repoing-cover.png` | Rendered from [cover.html](cover.html) at 1280 × 640 using the existing [repo.ing brand asset](../../public/gitcat.png). Also suitable as a repository social preview. |
| `explore.png` | Live `https://repo.ing/explore`, September 26, 2026 (Pacific). Main-content crop excludes the connected wallet header. |
| `analytics.png` | Live `https://repo.ing/stats`, September 26, 2026 (Pacific). Real indexed totals and UTC activity, with no demo values. |

Keep images local to the repository so GitHub renders them without a third-party image host. Capture fresh screenshots after material interface changes, preserve real values, and update the date. Do not include wallet popups, operator controls, credentials, or account menus.

To regenerate the cover, open `cover.html` in a browser at a 1280 × 640 viewport and capture it as PNG. The HTML retains editable type and layout; it uses the same cropped brand mark as the application.
